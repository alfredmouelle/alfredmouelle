# AuraTax: Canadian corporate, trust, and foreign tax filing

## The product

**AuraTax** is a Canadian tax platform developed by **AuraSoft Inc.** for accountants and enterprises to prepare and electronically file federal, provincial, trust, and international tax returns directly with the Canada Revenue Agency (CRA) and Revenu Québec.

## Supported returns and services

- **Corporate tax (T2, CO-17, AT1)**: full T2 preparation with Corporation Internet Filing, Auto-Fill My Return (AFR), pre-validation, document attachment, Québec CO-17, and Alberta AT1 (with automatic sync to its T2 counterpart).
- **Trust income tax (T3)**: preparation and electronic filing of trust returns and related schedules.
- **Foreign reporting & international returns**:
  - **T1135**: Foreign Income Verification Statement.
  - **T1134**: Information Return Relating to Controlled and Non-Controlled Foreign Affiliates.
  - **T106**: Information Return of Non-Arm's Length Transactions with Non-Residents.
  - **RC4649**: Country-by-Country Report.
- **Business authorizations (RC59 / XRC59)**: submit and cancel business consent for representatives directly through CRA web services.

## Key features

- **Automated validation and pre-validation**: real-time calculation engine with cross-schedule verification and CRA pre-filing validation checks.
- **Direct electronic transmission**: generates certified XML payloads and dispatches returns through CRA Internet Filing and Revenu Québec NetFile.
- **Web and desktop distribution**: cloud SaaS interface paired with an offline-capable desktop application for macOS and Windows.
- **Tax data security**: encrypted storage of financial records, role-based permissions, and multi-factor authentication.

## Tech stack

- **Backend**: Java Spring Boot handling tax calculation engines, schema validation, and CRA/Revenu Québec SOAP/REST transmission protocols.
- **Frontend**: Angular and TypeScript for dynamic schedule wizards, large data grids, and live calculation updates.
- **Database**: MongoDB storing nested multi-year return documents and audit trails.
- **Automated testing**: Cypress suites covering calculation edge cases, cross-form dependencies, and electronic filing payloads.
- **Desktop packaging**: Electron packaging for macOS and Windows.
