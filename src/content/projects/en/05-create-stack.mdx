# create-stack: compose your stack, ship a real app

## The product

**create-stack** is a command-line tool on npm (`@alfredmouelle/create-stack`) that scaffolds modular full-stack projects. Instead of template string replacements with empty placeholders, create-stack takes a fork-and-strip approach: it clones a fully wired base application and removes every library and configuration option you did not choose. The resulting repository passes type checking, lints cleanly, and boots right away.

Next.js App Router and TanStack Start are supported out of the box, with more frameworks planned.

## Key features

- **Framework choices**: scaffold Next.js (App Router) or TanStack Start apps with SSR, file routing, Tailwind v4, and Shadcn UI.
- **Interactive terminal wizard**: command-line prompt powered by `@clack/prompts`, with automatic fallback to non-interactive mode when CLI flags are provided.
- **Database drivers**: configure Drizzle (PostgreSQL with driver adapters, schema, and seed script), Prisma 7, Convex, or none for simple sites.
- **Auth and API**: better-auth (email/password, verification tokens, OAuth) or Clerk, paired with end-to-end type-safe tRPC v11.
- **Modular capabilities**: storage, cache, background jobs, structured logging, analytics, and error tracking isolated behind ports (hexagonal architecture) so you can change providers via environment variables.
- **Monorepo setup**: optional `--monorepo [turbo|nx]` flag scaffolds your application into `apps/web` within a configured Turborepo or Nx workspace.
- **Clean defaults**: strict Biome config, typed `env.ts` validation, Dockerfile, Git hooks, and a GitHub Actions CI workflow created upfront.

## Engineering and reliability

- **Automated test suite**: Vitest test coverage including smoke tests that generate full projects to verify dependency installation, type checking, and linting.
- **Matrix testing**: CI verifies both Next.js and TanStack Start configurations on every pull request.
- **Tokenless publishing**: automated npm releases using GitHub Actions OIDC Trusted Publishing with signed provenance.
- **Lightweight runtime**: pure ESM script with a single direct dependency (`@clack/prompts`) and no compilation step required to run.

## Tech stack

- **CLI core**: Node.js (>= 22), pure ESM, custom argument parser, `@clack/prompts`.
- **Monorepo distribution**: pnpm and Turborepo monorepo, packaged at `prepack`, published with GitHub Actions OIDC.
- **Generated application stack**: Next.js or TanStack Start, React 19, tRPC v11, Drizzle / Prisma / Convex, better-auth / Clerk, Tailwind v4, Valibot-typed environment variables.
- **Quality tooling**: Vitest, strict Biome v2 rules, GitHub Actions CI.

## My role
