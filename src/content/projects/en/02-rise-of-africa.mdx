# Rise of Africa: e-learning platform for financial education

## The product

**Rise of Africa** is a learning platform centered on trading and financial literacy. It unifies course content, community discussions, and student progress tracking in a single portal, taking learners from fundamentals to active practice.

## Member area

The student dashboard tracks completed video modules, watch time, upcoming live webinars, and key learning milestones through a personalized trader profile.

![Member dashboard](../_assets/roa.webp)

## Key features

- **Video courses & webinars**: modular curriculum with granular progress tracking and scheduled live sessions.
- **Trader profile**: personal dashboard with watch time stats and verified learning milestones.
- **Discussion forums**: community spaces organized by asset class and topic.
- **Anti-scam reporting**: verification and reporting tools to protect students from common trading scams.
- **Payments & subscriptions**: Stripe integration for one-time course purchases and recurring memberships.
- **Video delivery**: AWS S3 video storage with adaptive playback and web-push notifications for new content.
- **Admin back-office**: comprehensive management tools for student cohorts, video uploads, and revenue reporting.

![Member trader profile](../_assets/roa-trader.webp)

## Admin back-office

Platform administrators manage course releases, monitor student engagement metrics, and handle support requests from a unified back-office.

![Admin dashboard](../_assets/roa-admin-dashboard.webp)

![Course management on the admin side](../_assets/roa-admin-courses.webp)

## Tech stack

- **Application framework**: Next.js App Router with TypeScript.
- **API layer**: tRPC for type-safe client-server procedures.
- **Database**: PostgreSQL with Drizzle ORM.
- **Authentication**: better-auth.
- **Payments**: Stripe Checkout and Webhooks.
- **Media & storage**: AWS S3 for secure video delivery.
- **Notifications**: Web Push API and transactional email via Resend with React Email.
- **Background queues**: Inngest for asynchronous processing.
- **Testing**: Vitest for unit logic and Playwright for end-to-end flows.
