# create-stack : composez votre stack, lancez une vraie application

## Le produit

**create-stack** est un outil en ligne de commande disponible sur npm (`@alfredmouelle/create-stack`) pour générer des starters full-stack modulaires. Plutôt que d'assembler des templates textuels avec des placeholders vides, create-stack adopte une approche fork-and-strip : la CLI clone une application de base complète et retire proprement chaque librairie ou configuration non sélectionnée. Le projet résultant compile, passe le typecheck et s'exécute immédiatement.

Next.js (App Router) et TanStack Start sont pris en charge nativement, avec d'autres frameworks prévus.

## Fonctionnalités clés

- **Choix de framework** : génération d'applications Next.js ou TanStack Start avec SSR, routage par fichiers, Tailwind v4 et Shadcn UI.
- **Assistant interactif dans le terminal** : invite de commande guidée par `@clack/prompts`, avec bascule automatique en mode non-interactif lorsque des flags CLI sont fournis.
- **Pilotes de base de données** : configuration au choix de Drizzle (PostgreSQL avec adapter, schémas et script de seed), Prisma 7, Convex ou aucun pour un site vitrine.
- **Authentification et API** : better-auth (email/mot de passe, validation, OAuth) ou Clerk, associé à des procédures tRPC v11 typées de bout en bout.
- **Capabilities modulaires** : stockage de fichiers, cache, jobs en arrière-plan, logs structurés, analytics et suivi des erreurs isolés derrière des ports (architecture hexagonale) pour changer de fournisseur via une simple variable d'environnement.
- **Structure monorepo optionnelle** : le flag `--monorepo [turbo|nx]` place l'application dans `apps/web` au sein d'un workspace Turborepo ou Nx prêt à l'emploi.
- **Configuration propre dès l'initialisation** : règles Biome strictes, validation des variables d'environnement avec `env.ts`, Dockerfile, hooks Git et workflow CI GitHub Actions générés.

## Ingénierie et fiabilité

- **Suite de tests automatisée** : tests Vitest incluant des smoke tests qui génèrent un projet complet pour valider l'installation des dépendances, le typecheck et le linting.
- **Matrice de tests CI** : vérification systématique des configurations Next.js et TanStack Start à chaque pull request.
- **Publication sécurisée** : publication npm sans token via GitHub Actions OIDC Trusted Publishing avec signature de provenance.
- **Empreinte minimale** : script ESM pur sans étape de compilation intermédiaire et avec une seule dépendance directe (`@clack/prompts`).

## Stack technique

- **Cœur CLI** : Node.js (>= 22), ESM pur, analyseur d'arguments dédié, `@clack/prompts`.
- **Distribution** : monorepo pnpm et Turborepo, packaging au `prepack`, publication via GitHub Actions OIDC.
- **Stack applicative générée** : Next.js ou TanStack Start, React 19, tRPC v11, Drizzle / Prisma / Convex, better-auth / Clerk, Tailwind v4, validation d'environnement avec Valibot.
- **Outils qualité** : Vitest, règles strictes Biome v2, CI GitHub Actions.

## Mon rôle

J'ai conçu et développé create-stack sous licence open source MIT, en réalisant le moteur de composition fork-and-strip, les ports d'intégration modulaires, le wizard interactif en CLI, la suite de tests et le configurateur en ligne.
