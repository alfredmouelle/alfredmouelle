# Full-stack development and team lead on AuraTax

## Context

AuraSoft Inc. builds AuraTax, a Canadian tax SaaS and desktop application for preparing and electronically filing corporate returns (T2, CO-17, AT1), trust returns (T3), international information slips (T1135, T1134, T106, RC4649), and business consents (RC59 / XRC59) with the Canada Revenue Agency (CRA) and Revenu Québec. Each filing module requires hundreds of interdependent form fields, strict validation rules, and zero tolerance for calculation drift.

## My role

I joined AuraSoft in February 2022 as a full-stack developer working on both the Spring Boot backend and Angular client. In February 2024, I stepped into the Team Lead role, managing a team of developers while continuing to architect and write code for critical platform features and electronic filing web services.

## What I built and led

- **Spring Boot tax engines**: engineered calculation modules, validation schemas, and SOAP/REST transmission services for federal T2 (with Auto-Fill My Return and pre-validation), Québec CO-17, Alberta AT1, trust returns (T3), and foreign affiliate declarations (T1135, T1134, T106, RC4649).
- **Angular interface**: built responsive multi-step tax wizards and data grids in Angular and TypeScript, keeping deeply nested schedules accessible and fast.
- **MongoDB optimization**: structured document schemas for multi-year corporate return payloads and tuned database indexes to handle concurrency spikes during tax season.
- **E2E test suite with Cypress**: migrated legacy Protractor tests to Cypress, building a reliable automated test barrier across calculation paths and electronic filing payloads.
- **Team leadership**: led technical sprint planning, conducted thorough code reviews, and mentored developers to ensure compliance with annual CRA and Revenu Québec updates.

## Key takeaways

Tax software operates under strict regulatory constraints. A minor rounding discrepancy or XML schema error can cause tax authorities to reject an entire corporate filing. Leading development on AuraTax reinforced the value of exhaustive regression testing, defensive data modeling, and clear translation of complex tax legislation into resilient code.
