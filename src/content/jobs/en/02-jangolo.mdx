# Backend microservices for Jangolo

## Context

Jangolo is an agritech platform in Cameroon that connects farmers, distributors, and restaurants. The platform handles produce listings, bulk orders, and supplier deliveries. As traffic and feature requirements grew, the engineering team needed to split monolithic endpoints into modular microservices, integrate partner APIs, and document all public endpoints for client applications.

## My role

Working as a freelance backend developer, I implemented REST microservices in Laravel, routed traffic through AWS API Gateway, and documented all interfaces using OpenAPI 3.0.

## What I built

- **Laravel microservices**: built modular REST services to isolate order lifecycle processing, product catalog queries, and inventory updates.
- **AWS API Gateway management**: configured routes, authorization headers, request validation, and rate limiting across backend services.
- **API contracts with OpenAPI v3**: documented all endpoints with Swagger UI, giving mobile and web teams interactive, tested request-response specifications.
- **Third-party integrations**: connected external payment providers and SMS notification gateways with reliable webhook handling.

## Key takeaways

Working across distributed microservices made API documentation non-negotiable. Writing strict OpenAPI contracts before writing endpoint handlers eliminated integration guesswork and prevented schema mismatches between backend and client teams.
