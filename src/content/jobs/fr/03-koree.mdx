# Assurance qualité et développement mobile pour Koree

## Contexte

Koree est une application fintech déployée en Afrique francophone pour régler le problème du manque de pièces de monnaie chez les commerçants en digitalisant le rendu de monnaie sous forme de solde électronique et de cashback. L'écosystème réunit une application mobile grand public, une application commerçant (Koree Pro) et une API centrale en Laravel. Avec des transactions quotidiennes qui touchent directement au porte-monnaie des utilisateurs, les tests automatisés étaient indispensables pour éviter les régressions à chaque déploiement.

## Mon rôle

En tant que testeur QA et développeur freelance, j'ai mis en place les tests E2E sur les applications, écrit les tests backend avec PestPHP et Postman, et corrigé directement les bugs sur le code Flutter et Laravel.

## Ce que j'ai réalisé

- **Tests E2E avec Cypress** : tests des flux critiques sur Koree et Koree Pro (onboarding, calcul du cashback, encaissement marchand).
- **Tests backend avec PestPHP** : tests unitaires et d'intégration sur les calculs de solde, la logique de transaction et les règles de validation de l'API Laravel.
- **Validation d'API avec Postman** : collections de tests automatisées pour vérifier les réponses JSON, les codes d'erreur HTTP et le rafraîchissement des tokens.
- **Corrections sur l'application Flutter** : résolution de bugs d'affichage, de synchronisation d'état et de cas limites en mode hors-ligne.
- **Ajustements sur le backend Laravel** : correction des failles de validation et optimisation des requêtes SQL remontées par les tests.

## Ce que j'en retire

Sur une application de micro-transactions, une erreur de calcul de solde détruit immédiatement la confiance du commerçant et du client. Couvrir les calculs critiques avec PestPHP et les parcours d'encaissement avec Cypress nous a évité de livrer des régressions bêtes en production.
